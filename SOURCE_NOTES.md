# Source Notes

This repository was created from a supplied CMMI assignment and reorganized into a
public-facing technical reference.

## Privacy

The original source contains identifying information. That information is intentionally omitted
from this repository.

## Content handling

- The original PDF is not included.
- Original assignment screenshots and figures are not reproduced.
- Visualizations in `assets/` were recreated from the source concepts.
- Minor spelling and grammar issues were normalized for readability.
- Version-history language follows the supplied source rather than claiming to be a current
  authoritative release history.
